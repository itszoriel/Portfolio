# Resume fonts

The photo resume uses Montserrat Regular, SemiBold, and Bold to match the supplied
PDF reference. The TTFs come from the font author's repository:
https://github.com/JulietaUla/Montserrat/tree/master/fonts/ttf

`OFL-Montserrat.txt` is retained with the font files.

The ATS resume uses the user's installed Calibri fonts, matching the supplied Word
template. Calibri is read from Windows Fonts, or the `RESUME_CALIBRI_DIR` environment
variable. Microsoft font files are not copied into this repository.
